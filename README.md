# Eye Mark (Minecraft 1.20.1, Forge 47.2.0+)

Метка-глазок в точке мира (блок или воздух), видимая только выбранным игрокам.

## Команды (нужны права оператора, уровень 2)
- `/eyemark add <игроки> <x y z> [id] [run <команда>]` — поставить метку. Поддерживаются `~` и `^`.
  Пример: `/eyemark add @a 100 64 -20 door run say Нашли дверь!`
- `/eyemark remove <игроки> <id>` — убрать метку
- `/eyemark clear <игроки>` — убрать все метки
- `/eyemark list <игроки>` — список меток

## Поведение
- Метка на экране — глазок в круге на месте точки (с расстоянием в метрах).
- Метка за экраном — глазок на краю экрана со стрелкой в её сторону, пока игрок не повернётся.
- Прицел задел метку хоть на миг — через 2,5 с она плавно исчезает (и навсегда удаляется; привязанная команда выполняется в этот момент от имени игрока с правами 2).
- Метки хранятся в мире, привязаны к измерению, максимум 64 на игрока.
- Мод нужен и на сервере, и на клиенте.

## Сборка
Загрузите проект в репозиторий GitHub → Actions → Build mod → Artifacts → `eyemark-jar` → положите jar в `mods`.

## Звуки
Тихий стеклянный «звонок» при появлении новых меток и мягкий нисходящий звук, когда игрок посмотрел на метку (`assets/eyemark/sounds`, события `eyemark:mark_appear` / `eyemark:mark_seen`; громкость регулируется общей громкостью игры).
